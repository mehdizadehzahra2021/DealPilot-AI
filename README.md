DealPilot AI — B2B Lead Qualification & Outreach Prototype

Live Demo: https://mehdizadehzahra2021.github.io/DealPilot-AI/

Overview

DealPilot AI is an interactive frontend prototype that demonstrates a proposed AI-assisted workflow for B2B lead research, qualification, scoring, and personalized outreach.

The goal is to help businesses organize prospect research, evaluate potential customers against configurable criteria, and prepare more relevant outreach messages.

Key Features

Interactive workflow visualization
Configurable weighted lead-scoring concept
Evidence-based prospect qualification
Clear distinction between verified information, inferences, and unknowns
Example prospect records using fictional demo data
Outreach drafting concept with human review before sending

Tech Stack

HTML5
CSS3
JavaScript
GitHub Pages

Project Status

This is a frontend prototype and product workflow demonstration. It does not currently include a production backend, live company research integrations, persistent storage, or actual message delivery.

Future Improvements

Integrate a backend API and PostgreSQL database
Add live company research and source tracking
Integrate an LLM for research summaries and outreach drafts
Implement user authentication and audit logs
Add evaluation and human approval workflows

Responsible AI

The proposed workflow emphasizes transparent evidence, clearly labeled inferences, and human review before external communication.
